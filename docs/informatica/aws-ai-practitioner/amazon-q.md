# Amazon Q

Amazon Q es un asistente de IA generativa desarrollado por AWS, está diseñada específicamente para empresas y trabajadores. Ofrece configuración sencilla, no gestionas la infraestructura del modelo, tampoco decides qué modelos usar, pero tienes que subir documentos o dar fuentes de datos para darle contexto.

![alt text](https://static.seaflux.tech/media/blog/c983cba6-6be0-428d-81b5-578860df7dfc-banner.png)

## Amazon Q Business

En base a Amazon Bedrock, se genera un FM que te servirá como asistente inteligente, tiene todas las capacidades de un modelo generativo como realizar resúmenes, generar documentos con información empresarial, entre otros. Como una de sus características clave, es que el acceso a la información dependerá del tipo de usuario que esté consultando. En ese sentido, está integrado con el servicio de IAM para restringir accesos (Admin Controls).

Amazon Q Business tiene acceso a servicios internos (S3, RDS, ...) y externos como Microsoft 365, Salesforce, entre otros.

### Amazon Q Apps

Es una funcionalidad de Amazon Q Business que permite crear aplicaciones dentro del asistente ya creado. Concretamente elaboras un prompt para inducir al modelo a una respuesta consistente.

## Amazon Q Developer (Kiro)

Es un asistente que responde preguntas de la documentación de AWS y de los servicios de Amazon. También tiene acceso a tus recursos dentro de AWS, así que te facilitará información, comandos y sugerencias ante tus necesidades.

## Amazon Q for AWS services

Puedes encontrar Amazon Q como asistente en servicios como Quickshare, EC2, Chatbot, Glue...

## PartyRock

[Party Rock](https://partyrock.aws/) es un playground para crear modelos de ia generativa potenciado con Amazon Bedrock.
